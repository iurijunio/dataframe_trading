de qualquer tarefa.** Ele é a fonte única (regras, armadilhas, status e
pendências); este arquivo existe só para o Claude Code apontar para lá.
Mudou regra ou status, atualize o `AGENTS.md` — não escreva o conteúdo aqui.

Pontes específicas do Claude:

  (`.claude/launch.json`).
- Agentes do projeto em `.claude/agents/*.md` (revisor, mutacao,
  documentador, auditor, designer-ui).
